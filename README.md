# mini-suite · 百宝小屋

三合一微信小程序（练手/作品集项目）：**工具合集 + 壁纸/古诗词/表情包 + 演示商城 + 小游戏**。

- 平台：微信小程序（原生，tab：首页 / 我的，业务走四个分包）
- 后端：FastAPI + SQLAlchemy + SQLite（自建，演示态商城不接真实支付）
- 立项调研与方案：见工作区《三合一小程序-立项确认摘要.md》

## 功能总览

| 模块 | 功能 |
|---|---|
| 工具合集 | 二维码生成/扫描（历史互导）、图片压缩（批量）、倒计时、单位换算（7 类 34 单位）、房贷计算器、网络测速、分贝仪（iOS 降级）、亲戚称呼计算器（链式推算）、随机决定器（骰子/YesNo/抽签/转盘）、密码生成器（熵评估）、**番茄钟**（conic 环形进度/专注休息循环/今日统计）、**色值转换器**（HEX/RGB/HSL 互转/滑杆调色/历史色卡） |
| 内容 | 古诗词 2339 首（朝代/体裁筛选/**关键词搜索**/分页/收藏/复制/分享）、壁纸瀑布流（预览/保存/收藏）、表情包宫格、我的收藏聚合 |
| 商城 | 商品列表（**双列网格/已售角标/奇数留白**）/详情（轮播/数量步进/已售库存）、购物车（本地缓存/角标）、模拟下单支付、订单列表/详情（状态机流转/取消） |
| 游戏 | 2048（动画/撤销）、扫雷（三档）、记忆翻牌（4 关+瞬间记忆）、华容道（三档）、贪吃蛇（连贯蛇身）、霓虹方块（赛博朋克）、五子棋（启发式 AI）、推箱子（10 关 BFS 验证）、**数独**（挖洞生成+求解器唯一解保证/笔记模式/三档难度）、**打地鼠**（30 秒限时/连击加成/渐加速）、**24 点**（有理数精确运算/自动换可解题/看解） |
| 管理后台 | 商品 CRUD/上下架、订单全状态流转、媒体库上传/删除、统计面板 |

## 目录结构

```
mini-suite/
├── miniprogram/              # 微信小程序（开发者工具导入这个目录）
│   ├── pages/                # 主包：首页（四模块入口+emoji 图标+后端状态横幅）、我的
│   ├── packageTools/         # 分包：13 个工具（二维码/压缩/换算/房贷/倒计时/测速/分贝/亲戚/随机/密码/番茄钟/色值…）+ weapp-qrcode 库
│   ├── packageContent/       # 分包：诗词/壁纸/表情/收藏
│   ├── packageMall/          # 分包：商品/购物车/订单
│   ├── packageGames/         # 分包：11 个小游戏（2048/扫雷/翻牌/华容道/贪吃蛇/霓虹方块/五子棋/推箱子/数独/打地鼠/24点，*-logic.js 纯函数可单测）
│   └── utils/request.js      # 统一请求封装
├── server/                   # FastAPI 后端
│   ├── main.py               # 入口（端口 8790）
│   ├── app/models.py         # 8 张表
│   ├── app/routers/api.py    # 小程序 REST（含 /api/health /api/speedtest）
│   ├── app/routers/admin*.py # 管理后台页面 + 管理 API
│   ├── app/static/           # 壁纸/表情/商品图（30 张 PIL 自产 CC0）
│   ├── scripts/              # 诗词导入 / 素材生成 / 绑定脚本
│   └── tests/                # 回归测试脚本（S0/S2/S4/S6 四套）
└── 启动后端.bat
```

## 快速开始

1. **启动后端**：双击 `启动后端.bat`
   - 管理后台 http://localhost:8790/admin ｜ 接口文档 http://localhost:8790/docs
   - 首次启动自动建表；诗词 500 首（唐 300 / 词 200）已随库附带
2. **小程序**：微信开发者工具导入 `miniprogram/`（AppID 用测试号）
   - 首页顶部横幅绿=后端正常 / 红=后端未启动（工具模块不受影响）
3. **真机预览**：同一 WiFi，`app.js` 的 `apiBase` 改成电脑局域网 IP
4. **回归测试**：`cd server && python -m uvicorn main:app --port 8791` 后运行 `tests/` 下脚本

## 维护脚本（server 目录下）

```bash
python scripts/gen_assets.py            # 重生成演示素材（PIL 自产 CC0）

python scripts/bind_assets.py           # 重绑商品图与媒体索引
```

## 约定

- 演示态商城：订单状态机 pending → paid → shipped → done / closed；支付为模拟按钮
- 图片全走后端静态目录，小程序不打包图片资源
- 复用件（License 全部干净）：weapp-qrcode(MIT，附 LICENSE 于 packageTools/)、chinese-poetry 数据(MIT)、wechat-app-mall(Apache-2.0) 页面参考、ease-kit(MIT) 思路
- 数据清理顺序：OrderItem → Order → User（防孤儿订单 + SQLite 主键复用串数据）
